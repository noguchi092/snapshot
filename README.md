# スナップショット

写真と図面から工事指示書を作成する無料Webツールです。

## 機能

- 複数写真の読み込みとドラッグ＆ドロップによる並べ替え
- A4横4枚（写真下にコメント）/ A4縦3枚（右側にコメント）
- 写真連番と図面上の番号の連動
- PDF図面への番号・マーカー・矢印・丸・四角・文字・記号配置、Undo/Redo
- 印刷、PDF保存、写真入りExcel出力（コメント編集可能）
- 写真・図面はブラウザ内で処理。ページを閉じると作業内容は消えます。
